# ***📦 SEC556 v5 Official Hardware & Lab Kit***



<p align="center">
	<img src="../Images/Logos/SEC556_Kit.png">
</p>



This section contains photos and references related to the official **SANS SEC556 v5 IoT Penetration Testing hardware kit** used during the course.

The SEC556 kit includes multiple devices and tools used throughout the labs for:

- Hardware hacking.
- Firmware extraction.
- SDR experimentation.
- UART/JTAG/SPI analysis.
- RF communication testing.
- Embedded device analysis.
- Zigbee/Bluetooth/Wi-Fi research.
